# AD-25 — `/act`, the Get involved page

**22 August 2026.** The page the whole site already pointed at. Built, routed, and the four
dead hrefs that should have opened it repointed. Read `BRANDING-2026-08-21-frozen-language.md` first if you are
new to this; it is the design language this page is built from.

Also known as **"Three ways in"** — the frozen homepage's own name for band 12, which is the
door this page is the room behind.

---

## 1. Why this was the worst of the four

`design-routes.ts` has now recorded the same lesson four times: **a nav word, a built file
and a route are one change, not three, and any two without the third is a defect.** AD-22 was
`/impact` (nav word, no page). AD-24 was `/farm` (nav word pointing at a homepage anchor
whose own button was `href="#"`). This is the same screw, one turn further, and the count is
what makes it worse:

| Pointing at `/act` before this build | Where | Resolved to |
|---|---|---|
| The **Give chip** | the nav of every page on this site | the placeholder |
| **"Give monthly"** | frozen homepage band 12 | `href="#"` |
| **"See the dates"** | frozen homepage band 12 | `href="#"` |
| **"Work with us"** | frozen homepage band 12 | `href="#"` |
| **"Work with us"** | the frozen footer, on every page | `href="#"` |
| **22 named asks** | 18 WORK items + 4 kind landings | the placeholder |

So the most-linked destination on the site was the only page nobody had built, and
`design-routes.ts` named it as *deliberately* left alone. The 60-line Tailwind placeholder it
served said the volunteer sign-up "isn't connected yet" and disabled its own newsletter
input — honest, and read by anybody who clicked any of the above.

## 2. Rulings

### The owner's, 22 August

**G-1 · The Give ask routes to a human.** There is no payment destination anywhere in this
repository — no gateway, no UPI ID, no bank details, no donation URL — and none was invented.
The band states the ask, names the hole, and ends in an email. *A form that pretended to take
a card would be the exact defect this page was built to fix.*

**G-2 · Volunteer asks to be told.** All four gathering formats carry named holes saying we
cannot say when the last one ran, so this page does not say when the next one is. No
calendar, no invented dates. The ask is "tell us and we will tell you".

**G-3 · The ₹500 is carried and flagged.** The figure is used because the freeze makes the
homepage authoritative, and gate 5 asserts it still matches `home.html` so the two cannot
drift. **It is flagged here, not on the page:** see §6.1.

**G-4 · The phone number comes off the site.** Given mid-build: *"Remove my phone number from
the site."* It was published in two places — this page's closing band and `/farm`'s. Both are
gone, and **both generators now fail the build if it returns** (§4, gate 16). This supersedes
the phone half of `/farm`'s ruling F-2; F-2's actual point — the page ends in a *person*, not
a form — is unchanged, and that person is reached by email.

**G-5 · The name.** *"Swechha We for Change Foundation is the registered name. Usually we use
Swechha as the brand name. Use Swechha wherever possible, other than legal or statutory
requirement answers."* Three consequences, all applied:

1. **The case is `We for Change`, lowercase `for`.** It was written with a capital F on
   `/act`, on `/about`, and in the AD-21 ledger both were copied from. **Nothing could have
   caught it** — a capital in the middle of a legal name renders, passes every layout and
   contrast check, and reads as correct to anybody who has not been told. Only the owner
   saying so fixed it, so the wrong spelling is now *struck* and gated out of the built page,
   exactly as the phone number is.
2. **The frozen footer's legal name is completed.** It read `We for Change Foundation.` —
   missing the word *Swechha* — on **every page of this site**. This is AD-21 finding 2, open
   since 21 August and deferred there on the correct grounds that a legal name should not be
   changed in two places at once. The owner restating the name is the authority that was
   missing, so it is fixed now, in `home.html`, and propagated: **30 built pages carry the
   full registered name**, including the three dead prototypes (`system.html`,
   `situation-soon.html`, `work/_index-proposal.html`) — not because they ship, but because
   the component sheet is a plausible thing for a future session to copy a footer from.
3. **The long name is a statutory answer and appears exactly once per page in the body.**
   Everywhere the organisation is named in prose it is **Swechha**. On `/act` that is the one
   row in the legal band, and the band now says so in as many words: *"Everywhere else, on
   every page, the organisation is Swechha — that is the name it works under and the one
   people know. The long one belongs to the registrar."* Gated as a ratio, not a ban: one
   legal row legitimately needs the long form, and a second one in the body means somebody is
   using the registrar's name as the brand.

## 3. The architecture: the page is derived from the WORK section

A reader who clicked **"Bring your school"** on NatureScapes must find *"Bring your school"*
on this page, or the click lied. So the asks are **not typed here.** The build reads every
`data/work/*/*.json` plus `kinds.json`, takes every item whose `act.href` is `/act`, groups
them into the three ways through one small `WAYS` table, and renders each one as a link
**back to the page it came from**.

This is `/impact`'s figure architecture and `/farm`'s two resolved figures, applied to
inbound asks instead of numbers. What it buys:

- **A nineteenth ask cannot be added to the WORK section and left unanswered here.** Gate 1
  is *total*: a label no way claims stops the build with the label named and the file it came
  from. The `WAYS` table is the only typed thing about the list.
- **Every back-link is checked against `onward.json`'s route map** (gate 2), so the return
  paths cannot rot into 404s.
- **Six figures are resolved by label** out of the item that owns them — `Volunteers,
  annually` and `Colleges` and `Fellowships` from Influence, `Schools in Delhi` from Bridge
  the Gap, `Trees planted in Delhi NCR` from Monsoon Wooding, `Partner organisations` from
  Influence — and the build **dies if a label is renamed**. This page cannot come to disagree
  with the page a reader arrives from, which is the defect class that had the situation index
  printing 412 while the Air page said 387.
- **The four gathering formats come out of the events register with their holes attached.**
  That is what makes G-2 structural rather than editorial: the page physically carries
  "we cannot tell you when a Yamuna Shramdaan last ran" and then declines to name a date.
- **The five companies** are `monsoon-wooding.json`'s own `with.funders`, the only sourced
  list of corporate supporters on the site.

**Counts in prose are substituted, never typed.** One sentence says how many asks land here;
it is `{{ASKS}}` in the dataset, filled from the same count the masthead rail uses, and gate
15 fails on any unexpanded token.

## 5. Verification

Measured, not asserted. Dev server serving `public/` at the root; DOM measurement and
`::after` pseudo-boxes, per the AD-09 method.

- **No horizontal overflow at 320, 375, 1440, 1920** — `scrollWidth === innerWidth` at every
  one, no element right edge past the viewport. Document: 11,046px at 320 · 10,072 at 375 ·
  8,993 at 1920.
- **Tap targets: 39 controls, none under 24px, none under 44px, no expander collisions.**
  Nine links draw at 14–17px (the two funded things with pages, the four gathering formats,
  the three provenance links) and two at 37px (the email, twice). All take AD-09's
  transparent `::after` expander — the hit box grows, the drawn box does not. Clearances
  measured first, to the nearest horizontally-overlapping control: funds 107px · formats
  166px · provenance 80/246/265px, against the 13.5px each side that 17→44 costs.
- **Contrast, computed from rendered pixels against the composited ground: every text style
  ≥ 4.8:1.** Lowest is the onward-door heading at 4.80 (`--mustard-ink` `#8A6410` on paper,
  19px). Small caps labels 6.01. Nothing near the 4.5 floor by accident.
- **Focus visible on both grounds**, tested with a real `Tab` keypress rather than `.focus()`
  (which does not match `:focus-visible`): `solid 2px #E1A32B` on dark, `solid 2px #8A6410`
  on paper, 3px offset — the frozen ring, inherited, not re-declared.
- **Anchors land clear.** The header is `position: static` on this page set, so there is no
  sticky overlap: after a cold-hash jump to `#hands` the band heading sits 112px below the
  viewport top.
- **Console clean** (dev-server HMR and React DevTools notices only).
- **Partner doors align to the pixel.** All four rows across the three doors share their tops
  (379/515/718/825) — see §6.4.
- **`npm run verify:final -- --no-build`: 7 of 7 pages, 12 checks each, all pass.**
- **`npm run lint`: 0 errors** (22 pre-existing style warnings).

### The 900px phone band cap

Five of six bands exceed it. **Stated with the arithmetic rather than quietly breached**, per
AD-21 §10.4's precedent. For scale, `/farm` shipped on 22 August at **18,705px** at 375 with
**eight of nine** bands over the cap and one at 5,089px; `/act` is 10,072px with a largest
band of 2,732px. The cap is a *homepage* budget and no inner content page on this site meets
it. If it should come down here, the cut is the Volunteer band's ask list (8 rows) or the
four format blocks — but both are load-bearing: the ask list is the return path the whole
derivation exists to provide.

## 7. Google Forms

The owner asked twice: *should we have a Google Form to sign up to volunteer?* and *should
there be a contact us form?*

**Recommendation: one form, not three, and no separate contact form.**

A form is a *real destination* — it receives a submission — so for Volunteer and Partner it
is strictly better than a `mailto:`. It cannot help Give: **a form does not take money**, so
G-1's hole stands whatever is pasted in, and `channels.give.form` is rejected by the build if
somebody tries.

One form rather than one per way, because a person who wants to volunteer *and* bring their
school should not fill two, and because three response sheets is three inboxes nobody checks.
A first routing question does the work the three bands do editorially. And no separate
"contact us" form: it would duplicate the email that is already in the footer of every page
and split the inbox for no gain. **The email is the contact route.**

**Wired and waiting.** `data/act.json`'s `channels` holds one slot per way. Paste the real
*Send → link* URL and the CTA flips from `mailto:` to the form, opening in a new tab with
`rel="noopener"` and saying on the page that it goes to Google — this site names its
mechanisms. The build **rejects anything that is not a `docs.google.com/forms` URL**, because
a guessed or shortened form URL is a 404 behind a live-looking button, which is this page's
own founding defect.

**Nobody here can create the form** — it needs the owner's Google account. The questions
below are drafted so it can be built by pasting.

### The one form — "Get involved with Swechha"

| # | Question | Type | Notes |
|---|---|---|---|
| 1 | What are you writing about? | Multiple choice, required | *Volunteering · Bringing a school or group · A company or institutional partnership · Research or an organisation · Giving · Something else* — **this is the routing question**; use "Go to section based on answer" |
| 2 | Your name | Short answer, required | |
| 3 | Email | Short answer, required | |
| 4 | Phone or WhatsApp | Short answer, optional | **Optional, and say why:** "only if you would rather be called than emailed" |
| 5 | Where are you? | Short answer, required | Delhi/NCR or elsewhere decides what is actually possible |

**Volunteering section.** Which of these interests you *(checkboxes: river clean-ups and
shramdaan · planting · garden builds · scanning and archive days · whatever needs hands)* ·
How often *(one-off · a few times a year · monthly)* · Anything we should know (open) ·
**"We cannot promise a date yet — we will write when one is set."** That last line is G-2 on
the form as well as the page, and it is the sentence that keeps the form honest.

**School or group section.** School or organisation name · Your role · Year group / age ·
Roughly how many people · What you are after *(a day visit · a journey · a year-long
curriculum · not sure)* · When in the year.

**Company or institutional section.** Organisation · Your role · What you have in mind *(a
planting season · a ward or river stretch · funding a programme · employee volunteering ·
something else)* · Rough scale or budget, if you have one *(optional)*.

**Research or organisation section.** Organisation · What you are working on · What you need
from Swechha *(data · access · a cohort of volunteers · a collaboration)*.

**Giving section.** One line only, and it must not pretend: **"There is no payment page on
the site yet. Leave your email and we will send the details, including the 80G receipt."**
Then: monthly or one-off *(optional)*.

**Settings that matter.** Collect email addresses **on**; response receipts on; a
confirmation message that says *when* somebody will reply rather than "thanks"; and **do not**
make phone required.

## 8. Where this landed in git, and why the commit says something else

**This whole pass is inside commit `cd88325`, whose message is about the Farm School.** Two
sessions share this repository, and at 02:31 on 22 August a concurrent session's `git commit`
ran against a staged index that already held all of AD-25. Its message describes its own
change — the Farm School's thirty school groups a year, and the situation index's hero rhythm
— and says nothing about a new page, two site-wide rulings, or thirty rebuilt footers.

**Nothing is lost and the tree is correct.** `cd88325` carries all 43 files: `data/act.json`,
`scripts/build-act-page.mjs`, `public/design/v3/act.html`, this document, the `/act` route, the
completed registered name on 30 pages, and the struck phone number.

**The message was not rewritten, deliberately.** It was amended locally and the amend was
thrown away on discovering the commit had already been pushed. Force-pushing over a shared
branch that another live session is committing to would risk that session's next push and
desync its local clone — a worse defect than a misleading message, and the kind of thing that
cannot be undone by reading a document. So the record lives here instead, which is where this
repository keeps its records anyway.

**If the history is ever rewritten** — an interactive rebase before this branch merges, say —
the message `cd88325` should have carried is reconstructable from §1–§7 above.

**The lesson, for the next session that shares this repo with another:** `git add -A` stages
the *other* session's working tree too, and the window between staging and committing is long
enough for somebody else's `git commit` to claim it. Stage explicit pathspecs, or check
`git log -1` immediately after committing and before assuming the commit is yours.
